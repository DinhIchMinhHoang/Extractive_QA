# Extractive_QA — Trích xuất câu trả lời tiếng Việt

Mô hình trích câu trả lời từ đoạn văn ngữ cảnh cho sẵn, cho câu hỏi tiếng Việt.

- **Đầu vào:** câu hỏi + đoạn văn ngữ cảnh.
- **Đầu ra:** đoạn trích trong ngữ cảnh làm câu trả lời.
- **Dữ liệu:** UIT-ViQuAD 2.0.
- **Mô hình:** fine-tune PhoBERT hoặc XLM-R.
- **Đánh giá:** EM (Exact Match) và F1.

## Việc cần làm

- [ ] Chuẩn bị dữ liệu UIT-ViQuAD 2.0
- [ ] Fine-tune PhoBERT / XLM-R
- [ ] Đánh giá EM, F1
